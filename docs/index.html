Чат между телефонами — напрямую

p2pchat соединяет два устройства через интернет без центрального сервера для сообщений. Сервер нужен только на несколько секунд — помочь телефонам найти друг друга.

Как это работает

Два телефона соединяются друг с другом напрямую. Посредник участвует только в «знакомстве».

прямое соединение (основной путь) сервер знакомства (не видит сообщений) релей TURN (только при сложной сети)

Как начать

Нужны два Android-телефона и интернет. Регистрация не нужна.

1

Скачайте и установите приложение

Нажмите «Скачать APK» и установите на оба телефона. Если система предупредит — разрешите установку из этого источника.

2

Обменяйтесь ключами

В приложении показан ваш ключ. Передайте его любым способом (мессенджер, вслух, QR) человеку, с которым хотите общаться, и введите его ключ у себя.

3

Нажмите «Connect»

Телефоны найдут друг друга через сервер знакомства и установят прямое соединение. Занимает пару секунд.

4

Общайтесь

Пишите сообщения. Они идут напрямую между телефонами и зашифрованы.

Путь сообщения

Обычно напряжение уходит после нескольких шагов — дальше сервер не участвует.

Приватность и безопасность

Сервер не читает переписку

Через него проходит только техническая информация для соединения. Сообщения идут между телефонами.

Шифрование

Сообщения зашифрованы; ключ группы есть только у её участников. Пересылаемые через сеть копии не читаются посторонними.

Без регистрации

Ваш «аккаунт» — это ключ устройства. Ни телефона, ни почты, ни пароля.

Открытый код

Исходники доступны — можно проверить, как всё работает, и собрать самому.

Это ранняя версия для технически любопытных. Signaling идёт без TLS (ws://), а TURN-креды пока статические — для боевого использования нужен защищённый сервер.

Частые вопросы

Нужен ли сервер?
Для самих сообщений — нет. Небольшой сервер нужен только чтобы телефоны нашли друг друга, и ретранслятор — если оператор связи мешает прямому соединению.
Кто может прочитать мои сообщения?
Только участники чата, у которых есть групповой ключ.
Работает ли в мобильном интернете (LTE)?
Да. Операторы часто «прячут» устройства за общим адресом; тогда соединение идёт через ретранслятор TURN.
Можно ли в группы больше двух человек?
Ядро поддерживает группы; связь между участниками строится по принципу «каждый с соседями» и сообщения распространяются по сети.
Есть ли версия для iOS?
Пока только Android. Ядро кроссплатформенное, iOS — в планах.
