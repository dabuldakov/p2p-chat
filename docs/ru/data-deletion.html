Удаление данных

Обновлено: 23 октября 2026 г.

p2pchat не создаёт аккаунтов и не хранит ваши сообщения или историю групп на наших серверах. Данные хранятся на вашем устройстве.

Удаление данных на устройстве

  • Удаляйте отдельные сообщения в чате (долгий тап → «Удалить»).
  • Выйдите из группы, чтобы убрать её из приложения.
  • Очистите данные приложения: Настройки Android → Приложения → p2pchat → Память → Очистить данные.
  • Удалите приложение — вместе с ним удалятся локальные данные (включая ключ идентичности).

Сообщения, уже доставленные другим участникам, остаются на их устройствах; удалить их удалённо мы не можем. Можно попросить участников или владельца группы удалить их.

Удаление жалоб

Если вы отправляли жалобу, запросите её удаление письмом на dabuldakov@gmail.com. Укажите примерную дату/время и, если возможно, свой публичный ключ (короткий ID). Удаляем жалобы по запросу в течение 30 дней; автоматически — в течение 90 дней.

Аккаунта для удаления нет. Идентичность — это ключ, который хранится только на устройстве; удаление приложения или очистка данных удаляют его. Сохраните seed-фразу, если хотите восстановить идентичность позже.
